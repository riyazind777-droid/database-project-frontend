# 🚗 Luxury Car Database Management System

A full-stack **Luxury Car Database Management System** built with **React, Tailwind CSS, Node.js, Express.js, and MongoDB**.

This project demonstrates complete **CRUD operations, MongoDB query operators, REST API integration, and cloud deployment**.

## 📌 Project Overview

The Luxury Car Database Management System is a web application designed to manage luxury vehicle records stored in a MongoDB database.

Users can:

* Add new luxury cars
* View all cars
* Update car information
* Delete individual cars
* Delete all cars
* Update multiple records
* Filter cars using MongoDB query operators
* View car information in a responsive interface

The project was created to practice **MongoDB database operations and full-stack development**.

## ✨ Features

### 🚘 Car Management

* Add a new car
* Edit existing car details
* Delete a specific car
* Delete all cars
* Display all available cars
* Show car price, brand, year, fuel type and availability status

### 🔎 MongoDB Query Operations

The application demonstrates:

* `$gt` — Greater Than
* `$lt` — Less Than
* `$in` — Match values from a list
* `$and` — Multiple conditions
* `$or` — Alternative conditions
* `$exists` — Check whether a field exists

### 🔄 Database Operations

The project demonstrates:

* Create
* Read
* Update
* Delete
* Insert multiple documents
* Update multiple documents
* Delete multiple documents
* Conditional queries

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/riyazind777-droid/database-project-frontend.git
```

### 2. Navigate to the project

```bash
cd database-project-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run on the local Vite development server.
